# VanillaBrowser

A cloud-free browser core designed for local operation, prioritizing digital independence and strict privacy without reliance on external cloud services.

## Core Principles
* **Cloud-Free:** Operates entirely locally on the device.
* **Autarky:** Inspired by self-reliant architecture principles (independent core logic).
* **Privacy First:** No external server data leaks or unnecessary network dependencies.
